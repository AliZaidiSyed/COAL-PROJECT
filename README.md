# Door Security System 🔐

An Arduino-based door security system using a keypad to control access with a password.

### Features
- Password-based door access
- LCD display for status messages
- Buzzer for feedback
- Changeable password
- EEPROM integration

### Components
Arduino, 4x4 Keypad, I2C LCD, Buzzer, and Door Lock.
